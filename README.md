# Apex Stats

Локальная web-платформа для просмотра статистики матчей Apex Legends: турниры, матчи, игры, команды, карты, составы, оружие, тир-листы и просмотр обработанных результатов.

## Что входит

- `src/` - web-интерфейс на React, TanStack Router и Vite.
- `server/` - локальная API-часть авторизации для production/VPS.
- `dev/` - PowerShell-скрипты для запуска сайта и анализа видео.
- `scripts/tracking/` - локальный пайплайн обработки видео.
- `scripts/tracking/modules/plate_detector/` - интегрированный модуль поиска и идентификации плашек команд.
- `public/player-images/` - локальные WebP-фото игроков.
- `src/data/` - локальные JSON/snapshot-данные для web-интерфейса.

## Локальный запуск сайта

Требуется:

- Node.js 20.19+ или 22.12+;
- Bun;
- Git.

На новом ПК:

```powershell
git clone https://github.com/wi-us/apex-stats.git
cd apex-stats
bun install
bun run dev
```

Сайт откроется на:

```text
http://localhost:8080
```

Локальная авторизация создаёт администратора автоматически:

```text
email: admin@apex.local
password: admin12345
```

После входа пароль лучше заменить через админку пользователей.

## Альтернативный запуск через dev-скрипт

```powershell
cd dev
.\start-site-dev.ps1
```

Скрипт запускает Vite с локальным auth API.

## Production-сборка

```powershell
bun x vite build --config vite.dev.config.ts
```

Готовая статическая сборка появляется в `dist/`. Папка `dist/` и другие сборочные артефакты не коммитятся.

## Обработка видео

Аналитические скрипты запускаются локально на ПК пользователя и не требуются для обычного просмотра сайта. Быстрые PowerShell-точки входа находятся в `dev/`, а основные модули - в `scripts/tracking/`.

Видео, временные результаты, SQLite-файлы и тяжёлые артефакты обработки исключены из Git.

## Данные

Текущая версия сайта работает с локальными JSON/snapshot-данными. Supabase можно вернуть как внешний источник через переключатели окружения, но по умолчанию локальный запуск не зависит от неё.
