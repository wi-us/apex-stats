# Documentation

This folder separates **engineering** documentation from **diploma (VKR)** materials.

## Start here

- [`PROJECT_STRUCTURE.md`](PROJECT_STRUCTURE.md) — where to add code by concern
- [`CONTRIBUTING.md`](CONTRIBUTING.md) — what must not be committed, local checks

## Engineering

- **Architecture** (`architecture/`) — target state, API/database/diagram overviews
- **Runbooks** (`runbooks/`) — day-to-day operations, smoke tests, artifact policy
- **Specs** (`specs/`) — behavioural specs tied to ingest/detection modules

## Diploma (VKR)

- **Diploma** (`diploma/`) — chapters, plans, references, inventory
- **Drafts** (`../archive/diploma-drafts/`) — superseded chapter drafts kept for history
