Параметры HSV

На каждой дорожке два ползунка: слева — минимум диапазона, справа — максимум. Справа — бинарная маска (OpenCV H/S/V, как inRange): в диапазоне — белое, иначе — чёрное.

Пресеты для выбранной карты

Выбрать — подставить значения строки в фильтры (ползунки). Заменить — записать в строку текущие ползунки. Удалить — очистить строку. Квадрат цвета считается по средним H/S/V из записанных диапазонов (0–179 / 0–255).
