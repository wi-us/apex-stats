5 разных UX/UI дизайнов

Палитры: mono-pro и dark-esports. Отличаются не только цветом, но и информационной архитектурой и layout-паттернами.

  • Mission Control (dark-esports) — Командный центр: много данных на одном экране · home / match / admin
  • Cinematic Review (mono-pro) — Кино-режим: карта и таймлайн во фокусе · home / match / admin
  • Wizard Setup (dark-esports) — Пошаговая настройка матч -> карта -> фильтры -> админ · home / match / admin
  • Kanban Operations (mono-pro) — Операционный канбан по стадиям обработки карт · home / match / admin
  • Split Admin Live (dark-esports) — Одновременный live-плеер + админка сбоку · home / match / admin
